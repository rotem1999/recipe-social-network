# data-access-weather

Open-Meteo client, no key. Geocoding `OPENMETEO_GEOCODING_URL` (`name`, `count`, `language`) is forward-only: city → coordinates. Forecast `OPENMETEO_FORECAST_URL` (`latitude`, `longitude`, `timezone`) → `is_day`, `sunrise`, `sunset`, `weather_code`. Free tier: 600/min, 10,000/day, non-commercial only, CC-BY 4.0 attribution required.
